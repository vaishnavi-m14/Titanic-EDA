# Titanic Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis on the Titanic dataset using Python libraries such as Pandas, Matplotlib, and Seaborn. The goal is to extract insights about passenger demographics, survival rates, and relationships between features.

## Dataset
The dataset used is the classic Titanic passenger data, which includes information like passenger age, sex, class, fare, and survival status.

## Tools and Libraries
- Python 3.x
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook (or VS Code)

## What’s Inside
- `Titanic_EDA.ipynb` — Jupyter Notebook containing data exploration, visualizations, and observations.
- `Titanic_EDA.pdf` — PDF report exported from the notebook.
- (Optional) Any other supporting files.

## How to Run
1. Clone or download this repository.
2. Open `Titanic_EDA.ipynb` in Jupyter Notebook or VS Code.
3. Run all cells to reproduce the analysis and visuals.
4. Alternatively, review the `Titanic_EDA.pdf` for the complete report.

## Summary of Findings
- Majority of passengers were male and in 3rd class.
- Females had a higher survival rate than males.
- Passengers in 1st class had better chances of survival.
- Missing data present in Age, Cabin, and Embarked columns.
- Passenger class, sex, and fare are key factors related to survival.
